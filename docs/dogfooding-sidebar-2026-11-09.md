## 已完成的产品调整

- 新 Worker 主动保存短任务标题，新项目 Workspace 使用目录名，不再使用首项长任务目标。
- 工作面板提供“置顶主聊天”和“整理自动会话名”，复用 DSH 原生能力，不新增侧栏、聊天存储或生命周期框架。
- 整理仅处理当前 Bot、可证明由插件创建、已加载且自动来源的会话标题。保留用户名称、手工关联会话、取消置顶偏好及归属不明的历史。
- 不自动归档、取消归档或唤醒冷历史。原生 Workspace 没有标题来源记录，所以不凭名称相似度批量改旧分组。
- 创建、命名及持久化异常通过原有恢复流程收敛，不重复创建；补充了返回不同会话、错误归属、异步更换/归档和重试的回归。

## 本轮异常与恢复

外层曾直接向运行中的 Worker 追加收尾提示，触发已有的人工介入保护：旧 Run 终止授权并进入 recovery，没有伪造交付。外层移除排队提示，核对原生会话和后台工作停止后完成恢复；同一任务、同一 Worker 的新尝试重新核对代码并提交正式成果。未创建重复任务，也未把中断前代码视为已报告成果。

Bot 自动审查代码时达到既有的 5 分钟自动管理上限，未完成聊天交付。外层提供已核实的简短上下文后，Bot 沿用原结果记录审查并回到原对话交付，没有重新派发 Worker。此限制仍存在，不宣称已修复自动审查耗时或模型延迟问题。

现有 Worker 标题采用确定性截短，并非模型生成的语义摘要；复杂长目标可能仍需原生手动改名。历史会话保留，自动命名整理不等于历史归档。最终个人体验与接受成果仍由用户决定。
