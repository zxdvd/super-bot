# 01 Bot Workspace

职责：长期 Bot 配置、管理入口、领域职责和管理判断；不持有任务事实真源。

## 契约

- Bot 持久保存名字、职责、配置版本、显式知识/技能引用；每个 Bot 最多一个当前 Manager 绑定，历史保留。
- 管理 Session 的创建、替换和导航通过适配接口；关闭聊天不停止任务。卸载不能级联删除用户 Session。
- Manager 以分页任务摘要、未解决 Attention 和证据索引恢复上下文；长对话不是唯一工作记忆。
- 普通问答不强制建 Task；需要独立执行/持续跟进/验收时保存请求来源并创建任务。
- Manager 工具仅在有效 Manager 绑定作用域可用，默认不给任意写入 Shell；授权范围由应用服务核验。
- 每 Bot 同时一个管理轮次；重要变化持久排队，progress 不唤醒模型。过时通知可合并为当前摘要，但保留审计。
- 任务配置快照不因 Bot instructions 更新而静默扩大；新权限只经用户明确修改任务获得。
- Manager 仅使用现成确定性命令管理，不等待 Worker 完成；复杂检查可建立普通检查任务。

## 失败与边界

模型不可用只影响管理判断，面板查询/暂停/停止照常可用。自动验收和派发提交前再次校验 taskRevision、rowVersion、controlMode 和授权。存在未结束任务时拒绝删除 Bot；删除已无工作 Bot 也保留审计与原生会话。
