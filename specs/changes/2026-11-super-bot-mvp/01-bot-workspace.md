# 01 Bot Workspace

职责：长期 Bot 配置、管理入口、领域职责和管理判断；不持有任务事实真源。

## 当前产品入口（待实现）

按用户确认的 [聊天主流程](06-chat-first.md)，选择 Bot 默认进入它的对话；创建后自动准备对话，模型未配置时引导一次性设置。普通问答、工作澄清、接单和交付均围绕该对话，工作台作为辅助入口。用户不需要理解 Manager/Run 或手工派发。

复用当前 Manager 与重要事件队列，补齐面向用户的交付、对话回答/返工和明确的验收入口；请求来源、当前版本和权限由程序核对。C01～C06 是新的产品验收门槛，旧底层完成记录不代表这些行为已经实现。

## 契约

- Bot 持久保存名字、职责、配置版本、显式知识/技能引用；每个 Bot 最多一个当前 Manager 绑定，历史保留。
- 管理 Session 的创建、替换和导航通过适配接口；关闭聊天不停止任务。卸载不能级联删除用户 Session。
- Manager 以分页任务摘要、未解决 Attention 和证据索引恢复上下文；长对话不是唯一工作记忆。
- 普通问答不强制建 Task；需要独立执行/持续跟进/验收时保存请求来源并创建任务。
- Manager 工具仅在有效 Manager 绑定作用域可用，默认不给任意写入 Shell；授权范围由应用服务核验。
- 每 Bot 同时一个管理轮次；重要变化持久排队，progress 不唤醒模型。过时通知可合并为当前摘要，但保留审计。
- 任务配置快照不因 Bot instructions 更新而静默扩大；新权限只经用户明确修改任务获得。
- Manager 仅使用现成确定性命令管理，不等待 Worker 完成；复杂检查可建立普通检查任务。

## 失败与边界

模型不可用只影响管理判断，面板查询/暂停/停止照常可用。自动验收和派发提交前再次校验 taskRevision、rowVersion、controlMode 和授权。存在未结束任务时拒绝删除 Bot；删除已无工作 Bot 也保留审计与原生会话。

验收：T01、T02、T12、T13、T14、T20。实现：SB-03、SB-10、SB-11。


### 当前实现约束

管理上下文通过原生 Session 的作用域系统提示与单一管理工具提供，身份从实际 Agent 解析。自动唤醒使用持久 Outbox，单 Bot 串行，全局最多 2 个自动管理轮次；每轮 12 步/5 分钟，每 Bot 每小时 20 次自动唤醒。未知发送不自动重放，状态在管理设置中显示。空闲时可更换管理 Session，旧 Session 留存但管理工具立即失效。

### 配置更新与参考文本快照

Bot 可修改名称、职责和最多四份明确指定的本地 UTF-8 文本参考。保存时读取并保存内容快照与 SHA-256，每份最多 16 KiB，总计最多 64 KiB，不自动抓取链接或扫描目录。技能文件可作为文本参考，但不会扩大工具权限或自动安装技能。

每个新 Task 保存当时的 Bot 配置版本、职责与参考快照；后续 Bot 修改只影响之后创建的任务。Manager 查询旧任务时能读取该任务的原始快照。修改配置需旧管理会话空闲；保存会撤销旧 Manager 身份并保留历史，用户重新启用管理对话后使用新配置。执行中的 Worker 继续按任务原快照执行。无实质变化的保存不增加版本，也不撤销管理会话。
