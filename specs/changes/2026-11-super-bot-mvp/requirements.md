# 验收矩阵

以下先定义验收契约，再列当前证据与缺口。核心测试验证业务约束；确定性无网络模型配合真实 DSH 验证宿主行为，两者都不代表真实模型质量已通过。

| ID | 触发条件 | 必须可观察到的结果 | 验证层 / 任务 |
| --- | --- | --- | --- |
| T01 | 同 Bot 两个任务并行 | 消息、报告、产物不串线，分别可打开普通 Session | Fake + DSH / 05、06、12 |
| T02 | 管理 Session 替换或压缩 | Bot/Task 仍在，从账本恢复，历史可查 | DSH / 10、14 |
| T03 | 100 条混合状态任务 | 搜索/筛选/分页一致，全部人工待办可定位，不加载全量聊天 | UI + query / 04 |
| T04 | 重复命令、派发、报告 | 同键同内容单次生效；同键异内容拒绝 | DB + Fake / 03、06、13 |
| T05 | ready 缺证据或验收不符 | 不完成，保存候选并明确返工/人工事项 | Fake + DSH / 07、11 |
| T06 | 修改目标后旧 Run 返回 | 新 revision 不被旧报告完成；旧审计保留；旧执行未收敛不双跑 | DB + Fake / 07、09、13 |
| T07 | 回答、拒绝审批、接受成果 | 路由和版本正确；审批按宿主；完成与待办解决原子提交 | DSH + UI / 07、08 |
| T08 | 人工输入与 Manager 派发竞争 | 已验证顺序边界后暂停新派发；无法支持时明确要求显式接管且验证该路径 | DSH / 02、09、13 |
| T09 | turn 结束但工具/job/子任务尚在 | 不验收完成、不释放冲突资源、不派发第二 Run | DSH / 02、07、09、12 |
| T10 | 持久化/投递/通知边界重启 | 不丢责任，不盲重投未知输入，通知失败不重执行 | DB + Fake + DSH / 06、08、13、14 |
| T11 | 停止超时/外部效果未知 | 显示停止中/待核对，保留资源，旧结果不覆盖新状态 | DSH + Fake / 09、13 |
| T12 | 模型不可用或 Panel 离线重连 | 宿主在线时确定性查询/控制可用；离线快照过期且不重放变更 | UI + Fake / 04、10、15 |
| T13 | 越界访问或共享写目录冲突 | Manager/Worker 作用域拒绝越界；目录别名/重叠串行或隔离 | DB + DSH / 05、10、12 |
| T14 | 返工耗尽或执行收敛却漏报 | 有限续跑，转明确待办；重启不重置预算、不编造完成 | Fake + DSH / 11、12 |
| T15 | 新 schema/迁移失败/第二宿主启动 | 拒绝派发；失败可解释；原数据可恢复 | SQLite + process / 03、14 |
| T16 | Session 创建回执丢失或 Failed Run 仍占用资源 | 核对创建意图，不重复新建；Run 终态不让未知资源变空闲 | Fake + DSH / 05、12、13 |
| T17 | 任务有多个 Attention 且列表分页 | 计数单位清楚，同快照总数与筛选相符 | query + UI / 04 |
| T18 | ready 后文件内容变了/不可读 | 哈希或稳定版本核验失败，不接受失效成果 | filesystem + UI / 07、11 |
| T19 | cancel accepted 但 inbox 仍有自有输入，或 claimed 后被取消 | 撤回/核对自有输入；不删用户消息；claimed 不标已消费 | DSH / 02、08、09、13 |
| T20 | Manager 思考期间接管、改目标或耗尽额度 | 拒绝迟到派发/验收；保留审计；恢复需核对当前状态 | Fake + DSH / 10、11、13 |

自动验收的通过者记录为 Bot，humanAcceptedAt 只由经过认证的用户接受产生。所有安全/权限约束的通过以程序行为为准，不以模型口头承诺为准。
